## 📌 Overview

MindSpark is an interactive web application designed to make learning more engaging through quizzes and a modern user interface. The application focuses on delivering a seamless user experience with responsive design, secure authentication, and efficient data management.

This project demonstrates modern frontend development practices using React, TypeScript, Tailwind CSS, and Supabase.

---

## ✨ Features

- 🎯 Interactive quiz experience
- 🔐 User authentication
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- 🎨 Modern UI built with Tailwind CSS
- 🧩 Reusable React components
- ☁️ Supabase backend integration

## 🚀 Installation

Clone the repository

```bash
git clone YOUR_GITHUB_REPO_LINK
```

Navigate to the project

```bash
cd MindSpark
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
